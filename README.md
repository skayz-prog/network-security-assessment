# Network Security Assessment 

## Overview

This project is a practical network security assessment conducted in an isolated lab environment.

The objective is to simulate a real-world security assessment, identifying exposed services, potential vulnerabilities, security risks and recommended remediation measures.

## Objectives

- Perform network reconnaissance
- Identify live hosts
- Discover open ports and services
- Enumerate exposed services
- Identify potential vulnerabilities
- Assess security risks
- Document findings
- Provide remediation recommendations

## Methodology

The assessment follows the following methodology:

1. Reconnaissance
2. Network Scanning
3. Service Enumeration
4. Vulnerability Assessment
5. Risk Analysis
6. Remediation
7. Security Reporting

## Tools

- Nmap
- Gobuster
- Nikto
- Metasploit Framework
- Linux command-line tools

## Lab Environment

The assessment is performed exclusively in an isolated and authorized laboratory environment.

### Attacker

- Kali Linux

### Target

- Vulnerable Linux/Windows virtual machine

## Disclaimer

This project is intended for educational purposes and authorized security testing only.

No unauthorized systems or networks are targeted.
